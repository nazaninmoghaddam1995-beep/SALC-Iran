# SALC Iran
## Development History

This document records the development history of the SALC Iran
project and is intended to preserve the evolution of the product,
its structure, and its features over time.

---

## October 2026

### October 2026 — Initial Website Development

- Established the SALC Iran project concept.
- Designed the initial website structure.
- Created the main landing page.
- Created the About page.
- Created the Courses page.
- Created the Events & Community page.
- Created the Learning Resources page.
- Created the Learning Guides section.
- Created English learning level pathways.
- Created A1, A2, B1, and B2 level pages.
- Organized learning resources by English level.
- Integrated external learning resources into the level-specific
  learning paths.
- Designed the initial learner journey from choosing a level to
  accessing resources and learning support.

### Current Development Direction

The project is being developed from a basic informational website
toward an interactive online self-access language learning platform.

Future development areas include:

- Speaking Rooms
- Online community activities
- Personalized learning guidance
- Study planning
- AI-assisted learning
- Personalized practice
- Progress tracking
- Membership and other sustainable revenue models

---

## Development Principle

SALC Iran is intended to evolve gradually through documented
iterations.

New features, structural changes, and major product decisions should
be added to this document as the project develops.
