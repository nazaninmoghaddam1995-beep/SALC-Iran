# SALC Iran

**SALC Iran: An Online Self-Access Language Learning Platform (CEFR A1–B2)**

SALC Iran is an online self-access language learning platform
designed to help learners study independently through structured
learning paths, curated resources, speaking practice, learning
guidance, and community activities.

## Current Scope

The current platform focuses on English learning at CEFR levels:

- A1 — Beginner
- A2 — Elementary
- B1 — Intermediate
- B2 — Upper-Intermediate

## Core Features

- Level-based learning paths
- Listening, Reading, Speaking, and Grammar & Vocabulary resources
- Self-study resources
- Speaking Rooms
- Learning Guides
- Events & Community activities
- Structured learner journey

## Learning Journey

**Choose → Explore → Study → Practice → Get Guidance → Continue**

## Project Status

SALC Iran is currently in the early MVP / prototype stage.

The current development focuses on establishing the platform's
structure, learning paths, resources, and learner experience.

Future development may include:

- Personalized study plans
- AI-assisted learning
- AI speaking practice
- Writing feedback
- Personalized exercises
- Progress tracking
- Learner accounts
- Online booking
- Membership and payment features
